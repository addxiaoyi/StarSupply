# 国家 Faith 闭环补丁

第八份补丁 [starcore-faith-closure.patch](starcore-faith-closure.patch) 应用在 [Religion 补丁](RELIGION-CLOSURE.md) 之后。原始基线仍是 `f769e62799e769a18fe51305b545869a17f80cd1`；先依次应用后勤、玩家资金回执、税款回执、公共反馈、HUD、Clan、Religion 七份补丁，再应用本补丁。本轮没有推送 Core 仓库或声明生产 Folia 支持。

原国家 Faith 会在保存前清除 dirty、保存失败后仍显示成功；命令、交互、GUI 使用不同权限和冷却判断，祝福只有扣费与广播。现在每次接受的状态变化先原子落盘，命令使用权威结果，四类加成接入实际玩法。

## 保存与业务行为

- `faith.dat` v2 带 SHA-256 校验；完整校验旧版 v1 后迁移。祈祷次数、玩家冷却、每日登录、祝福期限、移除标记和维护日期一起保存。失败保留旧内存；写后响应丢失通过读取精确候选确认；无法判断的写入冻结后续修改。
- 启动时结算已过自然日衰减，变更前再检查日期，避免新国家或新奖励承担旧衰减。每日登录每玩家只能领取一次，切换国家、重连或重启不重置。祈祷每玩家冷却 60 秒、每国家每日最多配置次数，取消/忙碌/失败不会冒充成功。
- 多区域修改串行提交，读操作使用不可变已提交快照，不等待文件写入；旧引用在停用后不能继续修改。后台维护采用异步计时器，所有玩家反馈走实体 owner；退出不清空耐久冷却。
- 移除的国家信仰带墓碑，查询或重载不复活；管理员明确的 `set/add` 可重新启用。管理员参数按国家名或 UUID 解析；GUI、命令共用创始人/管理员及祈福权限判断。
- 满信仰里程碑保存通知冷却后广播，不另发奖励。国事日志观察已成功提交的祈祷事件；预提交的可取消事件不记为已成功。

## 实际加成范围

| 类型 | 实际行为 |
| --- | --- |
| 资源 / harvest | 国家资源区刷新产量增加，仍受每周期方块上限约束；普通库存转账、交易交付和退款不获得此加成 |
| 防御 / protection | 玩家近战、横扫、弹射物及爆炸伤害减免，合计最多 80%；虚空等环境伤害不适用 |
| 税收 / prosperity | 在扣款前提高应缴税额，交易报价不超过收入；只有实扣资金进入国库，退款使用同一金额 |
| 经验 / blessing | 玩家拾取经验增加，使用有界整数计算 |

等级被动加成来自配置；消费祝福另加 0.10，持续 30 分钟，同类型有效期间不可重复购买，期限跨重启保持。菜单和命令列表明确说明实际效果。税率扩展点也移到扣款前，修复旧代码只改返回值却不改变实扣/入账的问题；零税额扩展可以免征。已有资金回执继续重放原报价，不按当前加成重算。
