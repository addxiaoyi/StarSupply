# 旧 cuboid 领土权威 T1 开发检查点

日期：2026-11-27，Asia/Shanghai。

本阶段建立旧 UUID/cuboid 领土的不可变完整存档、严格文件导入及固定文件／SQLite 存储，并修复现有领土权限检查的实际拒绝行为。**新领土权威尚未接入运行时；旧 TerritoryService、SubRegionService 和 SQL 工厂的迁移仍待完成。** foundation 的世界＋chunk 领土是另一套权威，本阶段没有合并它们或启用割让和约。

## 同一存档中的父子区域

`CuboidTerritoryState` 保留父领土、子区域、权限、成员、国家、所有者、边界、类型、创建时间、启用状态和完整出生点。出生点保存世界名、坐标、朝向，不需要 Bukkit 世界已加载。所有集合均复制为不可变集合；子区域索引从权威关系派生，不另存可漂移索引。

每次提交核对完整前镜像并推进一次全局 revision；仅发生变化的实体推进 generation。删除原子保留完整前镜像和删除 revision，UUID 永久不能复用。父子 UUID 不得相撞，活动子区域必须在活动父领土内部；父领土删除必须同时删除其剩余子区域。跨实例观察允许合法跳过中间 revision，但禁止历史丢失、同版本改写、修改已删除记录和不可能的版本时间关系。

`CuboidTerritoryCodec` 使用 schema1 的确定性二进制行，明确验证 UTF-8、布尔值、行版本、长度、重复项、尾随内容与规范 Base64。未知字段、继承的 Properties 字段和不完整权限均拒绝读取。完整性封装、文件锁和 SQL CAS 使用已有 `DurablePropertiesStore`。

## 严格旧文件导入与固定后端

`CuboidTerritoryLegacyImport.inspect` 同时检查两份原始 Properties 字节，保存来源及 SHA256，区分不存在与存在但为空的文件。它不使用旧的容错 codec：缺字段、坏数字、重复 UUID、残缺权限、重复成员、父子索引不一致、孤立或越界子区域均使整个导入失败。旧格式的出生点世界名与坐标完整保留；旧格式从未记录朝向，导入时 yaw/pitch 为 0。不会扫描备份、选择新后端或修改原文件。

`CuboidTerritoryStorage` 必须显式初始化，只允许一次导入。文件与 SQLite 为固定后端；SQLite 每次连接核对真实产品、URL 和持久 main 文件，拒绝内存库、换库及额外 schema。SQL 故障或空表不能切换到旧文件。持久初始化标记防止记录删除后被当成新安装；关闭后读写及重新打开同实例均拒绝。

提交前检查完整序列化容量，并为所有活动实体的精确永久删除记录保留字节和下一代。真实文件与 SQLite 覆盖独立实例重启、CAS 冲突、初始化竞争、容量恰好足够／少一字节、文件写入失败、SQL 提交前回滚、提交成功丢回复及回读暂时不可用。文件跨进程锁复用既有实现，本阶段没有另跑多进程或 MySQL 验证。

## 已生效的旧权限修复

现有 `PermissionChecker` 将 `NONE` 作为明确禁止，普通成员、租客和子区域成员不能通过数值比较绕过。子区域租客使用子区域的实际要求，不再回读父领土较宽松的要求；未设置租客的活跃租约也不会空指针崩溃。所有者、管理员绕过和明确临时授权保留原优先级。

传送必须有启用的目标领土、可解析且位于其内部的出生点，并对该目标及出生点子区域检查权限；位置索引误报荒野不能绕过。预设解析对 null 返回 null，并使用固定 Locale.ROOT。旧 Mockito 夹具改为按测试提供实际使用的数据，补全临时权限的原领土 ID，保留严格检查；新增真实模型边界测试验证拒绝结果。
