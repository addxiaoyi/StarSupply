## 关闭屏障与永久身份

`ArmyNationClosure` 固定原操作编号、国家 UUID、接受时间和最终退役时间；终态保存本次清退的精确墓碑。关闭以国家 UUID 为键，同一操作不能换绑其他国家，也不能与 Army 其他账本编号相撞。只允许不存在、CLOSING、RETIRED 单向推进；不能删除、重开、更换原请求或另起解散编号接管。

`beginNationClosure` 单独保存关闭事实，不修改军队或其他账本。关闭后拒绝新的普通创建、替换、单独退役、付费准入、战斗、技能和后勤写入；外部伤害也不能绕过被关闭目标。开放国家的只读 SCOUT 仍可观察关闭目标。既有精确请求在准入检查前返回原结果；关闭不会清空历史技能冷却或重新施效。

`retireNation` 以原操作编号推进终态。终态重复调用返回原结果，传入的新时间不会改写已记录决定；新操作编号和与原关闭事实不一致的请求均拒绝。文件/SQLite 的相同前驱和完全相同目标 CAS 可以确认已经存在的同一结果；冲突请求仍必须重载后再处理。

## 已接受操作必须先结清

CLOSING 不是取消决定。此前已接受的付费请求继续按原编号查询、持久取消意图和确认；国库返回 APPLIED 时必须提交原请求的精确效果。不能因国家关闭、目录缺失或取消意图已经保存，就抛弃已扣款的创建/补给或假造退款。

ACTIVE 战斗保持双方完整冻结，仍只允许原 session 的成对完成或显式取消。关闭一国不会自动终止战斗、只删除本方或恢复旧快照。尚有本国 pending 付费或涉及本国的 ACTIVE session 时，最终退役失败关闭，等待原操作结清。

最终退役一次提交当前完整本国存活集合的下一代 `nation-retired` 墓碑和 RETIRED 事实；其他国家军队不变。已存在的 `battle-defeated`、`skill-defeated` 等墓碑原样保留，不重写原因、编号或代数。永久付费/战斗/技能/后勤证明、冷却链和迁移证据全部保留。

存储层独立验证这些约束，不依赖只走 owner 方法。跨多个 revision 的观察也只能从原 CLOSING 快照加上此前 pending 请求的精确已确认效果推导后继集合；不能借一次远距重载夹入额外代数、普通修改或遗漏退役目标。首次观察到的 pending 或 terminal 关闭事实也必须晚于此前已确认的本国历史；不会把关闭后才结清的原扣款或战斗误当成关闭前提。

## 容量、代数与格式

关闭前保留最终退役的一代 token，以及每个 CLOSING 国家额外一次 authority revision。pending 付费的预定 after、ACTIVE 战斗的潜在存活终态也必须再有退役后继，不能只检查当前代数；不足时在发布关闭前拒绝。既有 A3/A4 接受事实不会因此被改写或抛弃。

保存预算使用当前映像、全部付费/战斗最大完成映像和全部关闭国家最终退役映像的属性并集，逐键取序列化长度上界，再保留最大 revision 字符宽度。这是保守容量预留，可能大于任何单一可达快照；临时预算 Properties 只用于计数，绝不会解码为有效业务状态或写入存储。大小不同的世界名和多个国家的中间阶段不会通过仅比较起点/终点总大小漏掉峰值。编码值是 Base64 行及 ASCII 元数据，内嵌文本不直接进入 Properties 值。

schema5 新增 `armyNationClosure.` row 8，包含完整请求、严格 0/1 终态标记、退役时间和按 UUID 排序的有界精确墓碑集合。原 schema1–4 和 6/8/9/10 参数构造器保留；旧 schema 不接受新行，所有旧 owner draft、付费/战斗未来映像和 `withRevision` 均保留新账本，禁止降级。错键、重复/乱序、非法 flag、矛盾阶段、尾字节和缺失终态证明均拒绝。
