## 完整快照写入

创建、元数据、所有权、成员、权限模板、子区域继承和优先级操作都要求与读取时完整快照相同的前镜像。父领土删除和按 owner 批量删除，同次保存所有相关子区域的精确删除前镜像。创建时检查历史 UUID、同名及重叠；子区域同时检查父领土、范围、最小尺寸和同级重叠。调用者明确选择允许父领土重叠，但仍不能覆盖 UUID 或同名记录。

任何中间写入都会使旧请求失效，包括权限检查后发生的所有权变化。视图内部保存不可变来源快照；直接修改显示对象后调用 save 不会写回这些字段。普通成员不允许使用 OWNER 级别，转移所有权会移除新 owner 的潜在普通成员记录。内部组件不替代玩家权限检查，生产入口迁移仍必须检查当前身份与对应快照。

世界解析仅用于显示，未加载的出生点不因成员或模板操作而被擦除。模板应用保留其他元数据；子区域模板替换覆盖权限并关闭继承。优先级调整以准确大整数体积排序，处理旧导入数据的重叠冲突；空间耗尽时不发布部分结果。

## 旧 API 适配

新服务覆盖旧父/子服务的全部公开实例方法，查询只读取共享确认状态，返回独立视图。测试检查新公开旧方法不能遗漏覆盖，以防意外使用另一份旧缓存或 writer。

所有写入已经在返回前确认；save 和 saveAsync 仅检查可用状态，不拿视图重建存档。clearAll 暂停两个服务且不删除存档，load 或 refresh 成功后恢复。保存冲突或确认丢失后两服务都不可读写，显式刷新才能恢复。关闭永久退役共享入口。

`getClaimsByNation` 保留旧 ownerId 查询语义；当前攻城和旧和约代码也把 nation UUID 用作 ownerId，不能仅凭名称改为 affiliation nationId。条件转移的同 owner 重试仍只是兼容语义，**不构成战争、割让或和约的耐久业务回执**。

同时修复现有 Territory/SubRegion 体积、面积和中心点的整数溢出；固定公开返回类型溢出时取上限，新服务的位置排序使用准确体积。
