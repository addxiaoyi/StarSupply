## 协议与保存边界

WarDeclarationRecoveryService.Request 保存操作 UUID、原发起方、进攻国、防守国和 WarGoal；只有进攻国能发起，双方不能相同。首次保存前检查现有战争、冷却及保护条件。原报价随 PENDING 意图写入战争权威，重启或修改配置不会重新报价；空报价、负报价、非精确分金额及超过上限的报价被拒绝，不能被解释成免费宣战。合法零费用仍走持久意图与终态。

PENDING 不创建可运行的战争，不进入战争注册表、战争阶段任务或准备期计时；它预留双方国家组合，并阻止任一方解散/退役。战争编号固定等于原操作 UUID。准备期的 declaredAt 在战争终态成功发布时确定，等待费用确认不会消耗准备期。

国库 NationDebitService 使用相同 UUID、原进攻国、原费用和固定用途前缀 war-declaration: 加原 UUID。同号请求的国家、金额或用途不一致会被拒绝。扣款决定与余额同次 CAS 保存；已扣、余额不足、退役拒绝及取消封存均是不可变回执，重试不能把拒绝变成新扣款。金额只接受精确到分的正金额，上限为 10^15。零费用宣战不调用扣款服务。

战争权威必须读回完全一致的国库回执。确认 APPLIED 后，原 WAR 和 DECLARED 回执在同一次战争权威提交中发布；确认余额不足或退役后发布 REJECTED。读回暂不可用、版本冲突或提交响应丢失不能当作“未扣款”，保持待恢复并凭原号继续。战争终态不可改写；重试已结束战争的旧操作不会重建战争。

WarModule 启用时先安装单调的 paidDeclarations.enforced 标记，再暴露服务，并恢复 PENDING 意图。标记安装后，新 WAR 必须有同号 DECLARED 回执，普通低层写入不能绕过费用协议。已有历史战争不追扣费用；不能通过重用旧 WAR 编号、改变其原始双方/目标/宣战时间或复活 ENDED 状态绕过限制。

国库快照保存扣款历史，文件权威另有永久 initialized 标记，用于区别真正未初始化和确认历史丢失。已初始化后的主文件丢失、损坏标记或不一致历史会拒绝服务，不会自动新建空国库。旧文件格式仍可读取，后续保存安装标记；迁移时应保留已初始化标记、业务文件及稳定锁文件。

## 恢复与安全取消

公开服务提供 declareWarWithReceipt、recoverWarDeclaration、cancelWarDeclaration、warDeclaration 和 pendingWarDeclarations。管理命令使用 starcore.war.admin 权限：

~~~text
/war declarationrecovery list
/war declarationrecovery show <UUID>
/war declarationrecovery retry <UUID>
/war declarationrecovery cancel <UUID>
~~~

list/show 只查询；retry 和 cancel 始终使用原 UUID。未知操作拒绝处理，不会替换成一个新操作。普通 boolean 宣战入口会继续同方向的原待恢复操作；返回 false 或抛出异常不证明未扣费，应查询原回执。

| 原状态/资金决定 | cancel 的结果 |
| --- | --- |
| PENDING，原扣款尚未决定 | 国库以原请求永久封存 CANCELLED，战争权威确认后发布 CANCELLED 并释放双方预留；迟到 declare/retry 不再扣款 |
| PENDING，国库已经 APPLIED | 继续发布原 DECLARED 战争；不会取消战争或退款，也不会再扣一次 |
| PENDING，国库已拒绝原请求 | 发布原 REJECTED，不改写为另一种资金决定 |
| 零费用 PENDING | 可直接发布 CANCELLED 并释放预留 |
| 正费用但服务/回执暂不可用 | 不能证明原扣款未提交，保留 PENDING；恢复可读后按原决定继续 |
| DECLARED / REJECTED / CANCELLED | 返回原终态，不重建战争、不更改费用、不重新发布旧效果 |

战争终态响应丢失时通过读回确认；取消回执暂不可读时继续阻止解散和同一组合的新宣战。待战争权威确认原终态后才能释放待恢复预留。此取消协议仅适用于本轮宣战意图，不代表已实现和约、实际赔款、普通转账、预算或国家解散已接受预留的安全取消。

## 外交、事件与兼容镜像边界

费用确认与战争终态成功后，WarModule 才尝试同步外交关系及兼容索引。镜像失败会记录错误，已经确认的战争不会反向回滚或退款。重放已终结的宣战操作不会再次发送原宣战镜像；启动时仍从战争权威重建当前兼容索引。

外交接收端仍通过没有战争编号的 recordWarDeclaration/setRelation 保存状态。旧结束回调也仍可无条件写 NEUTRAL；缺接收端原操作编号、源版本和结束围栏，因此本轮没有关闭较晚旧回调覆盖较新关系的问题。宣战/战争事件与镜像也没有耐久投递确认。普通结盟/解约与和约政治、领土、军队效果仍需分别实现接收端回执，不能用战争费用恢复代替这些工作。
