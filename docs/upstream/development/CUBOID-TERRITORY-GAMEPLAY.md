# Cuboid 游戏事件保护与区域显示 T8 开发检查点

日期：2026-11-28，Asia/Shanghai。

`StarCorePlugin` 已注册 `CuboidProtectionListener`，坐标领土权限开始作用于实际事件入口，并与既有 chunk 领土保护共同生效。`PermissionChecker.hasPermissions` 对一次事件的全部位置使用同一份父子快照，外部权限查询后复验权威未变化。未知、无效坐标或权威不可用时拒绝操作，包括管理员与表面上的荒野；未完成首次来源选择的服务器会阻止这些受保护事件，管理员需要先配置并恢复。

## 已连接的事件

方块破坏、单/多方块放置、容器/双箱、物理交互、桶、骨粉变化列表、耕地/收获、实体交互/展示框/盔甲架/剪毛、载具/骑乘、传送/传送门、直接与投射物伤害、宠物、药水/滞留云、玩家引火、自然怪物生成、方块/实体爆炸和爆炸伤害均接入权限。权限判断不会重新允许其他插件已取消的事件。空气交互只设置 DENY 通道，避免清除 Bukkit 自身的预取消。

多方块放置、桶实际目标、双箱两侧、骨粉所有变更方块和爆炸全部影响方块共同检查；其中一个位置不允许时拒绝整次操作。漏斗运输/拾取、活塞伸缩、流体和火势跨越父领土或子区域边界时拒绝；同一 owner 的不同区域也不自动放行。活塞按原方块朝向推导移动方向，不跨区块加载。

Folia 中，同步事件若需要查询另一 region 所属玩家的权限则拒绝，不跨线程读取该玩家。来自远处的箭/TNT等可能因此被拒绝，尚未实现分布式权限租约。插件没有在事件内启动异步任务后再改变取消状态。

环境事件没有玩家角色：SPAWN_MOBS/EXPLOSION 的 NONE 代表禁止，其他级别允许；玩家刷怪蛋、玩家来源爆炸仍按角色级别、owner/admin/临时授权检查。该区别显示在权限说明。未列入成员表的玩家按 VISITOR，明确 NONE 成员仍受限，使商店/竞技场等访客模板真正可用。

临时授权现在绑定父记录以及该父下全部子记录 generation，包含已删除记录。创建后再删除子区域不能复活旧授权；子区域变更需要重新授权。授权仍在内存中，不声称重启保留。

## 区域显示

`TerritoryLocationView` 从一个快照返回父子显示对象并复验。RegionIntegrationService 先读取该结果；不可用时不继续猜测 chunk 国家或生物群系。`/region info` 明确提示信息不可用；缺失世界数据也不伪造荒野或 Plains。确认没有坐标领土时保留原 chunk/生物群系显示路径。实服 Biome 注册表显示未在本轮验证。
