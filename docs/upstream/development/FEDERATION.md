## 本轮实现

- 独立 `module.alliance` 多国联盟的联盟、成员、国家索引、邀请、关系和公告进入一个权威快照，与退役回执及解散历史同次保存。文件及 SQL 固定后端、版本比较、校验和、读回确认接通；普通修改成功返回前完成持久提交。
- 国家退役清除其成员身份、收到或发出的邀请、署名公告。盟主退役依次按官员优先、加入时间、国家 UUID 选择继任者；最后一员退役时解散联盟并清理关系和邀请。回执永久保留原操作号及原结果，后续继任者退役不会改写旧回执。
- 成员索引必须一致，联盟只允许一名正确盟主，退役国家和已解散联盟不能被迟到快照复活。两个实例竞争不同退役号时只接受一个结果；同一存储实例刷新后也不能把新版本借给旧选区。
- 实际国家解散在保存意图前要求多国联盟服务支持持久退役，清理时核对原事务号及国家回执。启动恢复还会根据旧共享 `COMPLETED` 记录补齐多国联盟退役；补齐失败暂停新生命周期、经验及停用保存，原完成历史保持不变。旧独立日志仍需独立证据处理。
- 事件在提交之后发送，回调期间不持有联盟监视器，拒绝写入重入。停用取消所属定时器，旧任务与旧服务不能继续写；启用失败清理服务、监听器及自有命令，保留后来替换的注册。
- 严格迁移旧六文件：已有数据时任一文件缺失、损坏、重复字段、成员索引不一致均拒绝加载。合法注释空文件可迁移，分隔符和多行文本保留。切换到 SQL 优先迁移已封存的新文件，不会绕过缺失文件的备份、临时文件或初始化标记重新导入旧数据。原六文件不改写。
