## 使用与行为

拥有 `starcore.admin` 权限的玩家或控制台可执行：

```text
/nation disbandrecovery list [页码]
/nation disbandrecovery show <完整操作 UUID> [目标页码]
/nation disbandrecovery retry <完整操作 UUID>
```

列表显示待清理或待核实的原解散记录，每页 20 条；详情显示原国家编号并支持目标分页。查询只读取目录与回执，不执行外部清理。编号必须完整，权限不足、命令停用、错误参数和未知编号不会创建新操作。重试沿原事务号继续清理，已完成请求只核实或补齐联盟回执，不创建新解散、不撤销既有退役。

返回状态区分 `CLEANUP_PENDING`、旧共享历史的 `FEDERATION_PENDING`、回执暂不可读的 `VERIFICATION_UNAVAILABLE`、编号或国家不匹配的 `CONFLICT`，以及已完成且联盟回执已核实的 `COMPLETED`。缺失或冲突回执不会被显示为已核实完成；旧共享历史补齐未完成时继续阻止新的国家写入。

`NationDisbandService` 通过模块服务注册与 `StarCoreApi.nationDisbandService()` 提供同样的查询和原号重试能力。调用 API 的扩展需自行授权。启动恢复暂时失败会记录警告并保留管理入口，国家写入仍受待恢复状态阻止。权威存储无法读回导致冻结时仍需恢复存储并重新加载实例；该命令不绕过冻结或旧独立日志屏障。
